strandwire
====

English | [한국어](README.ko.md)

A personal network server/client project.

- Stack: standalone asio 1.38.2 + C++20 coroutines, protobuf 3.21.12, spdlog 1.17.0, CMake 3.21+
- Verified on: Windows (MSVC), Linux (g++ 11), macOS (Apple clang 21)
- Protocol: LPN framing with a protobuf body. Tunnels (one logical channel per service type),
  tunnel operations, heartbeats, and a msgid that is the FNV-1a hash of the message name

Components
---

| Name | What it is |
|---|---|
| `LogLib` | Wrapper around spdlog's asynchronous logger |
| `ProtoLib` | `.proto` files and generated code |
| `ServerLib` | Server logic (asio, strand-based multithreading) |
| `NetworkServer` | Server executable |
| `NetworkClient` | Interactive console client |
| `DummyClient` | Load-test client |
| `common/lpn` | Wire protocol implementation (header-only) |
| `tests` | `wire_test` (byte level), `smoke_test` (in-process end to end), `app_test` (settings and start-up phases) |

Build
---

```
git submodule update --init
cmake --preset windows-msvc    # or linux / macos
cmake --build --preset windows-msvc
ctest --preset windows-msvc
```

- On Windows the Ninja preset needs a Visual Studio developer command prompt.
- The first build compiles protobuf from source and takes a few extra minutes.

Visual Studio (Windows)
---

1. On a new PC, install protobuf once:
   ```
   powershell -ExecutionPolicy Bypass -File tools\build_protobuf.ps1
   ```
2. Open `strandwire.sln` in VS 2022 or later.

- Configurations: `Debug|x64`, `Release|x64`. Output: `build\vs\<Configuration>\bin\`.
- Shared settings: `strandwire.config.props`, `strandwire.props`.
- The solution is maintained by hand, not generated by CMake. When you add or remove a source
  file, update the vcxproj and `CMakeLists.txt` together. The CTest `check_vs_sync` fails if they
  differ.

Run
---

```
NetworkServer --sid 0.0.11.1 --config lobby_config.json   # ESC or Ctrl+C stops it
NetworkClient 127.0.0.1 10000 <name>
DummyClient --ip 127.0.0.1 --port 10000 --session 100 --duration 10
```

The server's command line names the instance (`--ip`, `--sid`) and its environment file (`--config`); the file
holds port, threads, timeout and log settings. See `NetworkServer/lobby_config.example.json`. Without a file it
listens on port 10000. The clients accept `--log-level <level>` and `--log-dir <folder>` (no file log by default).
